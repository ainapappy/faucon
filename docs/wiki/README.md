# 📖 Wiki Faucon

Le wiki est l'espace de référence **transversal** : il sert autant la lecture de la
[doc d'utilisation](../usage/README.md) que celle de la [doc technique](../technical/README.md).

## Pages

- **[dictionnaire.md](dictionnaire.md)** — le dictionnaire des termes techniques. Chaque terme
  utilisé ailleurs dans la doc y est défini, dans le contexte de Faucon, avec des liens vers la
  page qui le détaille.

## Convention de la doc vis-à-vis du dictionnaire

- La doc d'**utilisation** évite le jargon quand c'est possible ; quand un terme technique est
  incontournable, il est écrit **en gras à sa première occurrence** et renvoie au dictionnaire.
- La doc **technique** suppose le dictionnaire lu : elle l'utilise comme vocabulaire commun.

## Étendre le wiki

Toute nouvelle page du wiki doit rester transversale (ni guide produit, ni guide développeur).
Un concept qui appartient à un seul des deux mondes a sa place dans l'espace correspondant,
pas ici.
